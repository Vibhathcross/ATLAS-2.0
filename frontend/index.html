SYSTEM POWER & SECURITY
"Shutdown" / "Power off"
Gracefully initiates system shutdown with 10-second grace buffer.
"Cancel shutdown" / "Abort shutdown"
Cancels any scheduled system shutdown timer.
"Restart" / "Reboot"
Reboots the operating system safely.
"Lock computer" / "Lock screen"
Instantly locks the Windows user session.
"Sleep computer" / "Go to sleep"
Places the computer into low-power sleep state.
DESKTOP & WINDOW WORKSPACE
"Clear all apps" / "Clear screen"
Minimizes all clutter and returns to a clean desktop view.
"Show desktop" / "Minimize all"
Toggles desktop view using Windows shortcut hotkey.
APPLICATION CONTROLLER
"Open Chrome" / "Launch browser"
Launches Google Chrome browser.
"Open Code" / "Launch VS Code"
Launches Visual Studio Code workspace.
"Open Spotify"
Opens the Spotify desktop music player.
"Open Notepad"
Opens Windows Notepad for quick text drafting.
"Open Calculator" / "Open Calc"
Launches Windows Calculator.
"Close Chrome" / "Close Notepad"
Terminates active process instances of the target application.
AUDIO & VOLUME
"Volume up" / "Louder"
Increases master output volume by 5 steps.
"Volume down" / "Quieter"
Decreases master output volume by 5 steps.
"Mute" / "Unmute"
Toggles master audio mute state.
KEYBOARD & SYSTEM REFRESH
"autokeyboard <keys>"
Press any key or combination up to 10 keys (e.g. autokeyboard win+d, alt+f4, ctrl+c).
"f:<command>"
Force Send Now to Antigravity immediately without waiting for current running task.
"#anti" / "toggle antigravity"
Toggles Antigravity Mode on/off instantly without opening Settings.
"selfrefresh" / "restart atlas"
Gracefully restarts ATLAS 2.0 and reloads all updated features.
SYSTEM DIAGNOSTICS
"System status" / "System health"
Queries real-time CPU %, RAM usage (GB/total), and battery level.
